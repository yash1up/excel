# Swiggy Data Analysis Project-
Project Overview
This project focuses on analysing Swiggy restaurant and food-order data
using Microsoft Excel. The objective is to explore restaurant
performance, food pricing, customer ratings, order patterns and revenue
distribution across cities and food categories.

The workbook includes a raw dataset, pivot-table analysis and a
dashboard-oriented worksheet structure.
Dataset Overview
The main dataset contains 197,430 records and 10 columns,
covering the period 1 January 2025 to 31 August 2025.

  Column              Description
  State             State in which the restaurant is located
City              City associated with the restaurant
Order Date        Date of the order
Restaurant Name   Name of the restaurant
Location          Restaurant locality
Category          Food category
Dish Name         Name of the dish
Price (INR)       Price of the dish in Indian rupees
Rating            Customer rating
Rating Count      Number of ratings recorded
Workbook Structure
The Excel workbook contains the following worksheets:
- Swiggy Data -- Main dataset containing restaurant and dish-level
  records.
- pivot table -- Pivot-table summaries and calculated metrics.
- Dishes -- Worksheet included in the workbook.
- Restaurant -- Worksheet included in the workbook.
- Sales -- Worksheet included in the workbook.
- Dashboard -- Dashboard worksheet included in the workbook.

Analysis Included
The pivot-table worksheet contains summaries for:
- Total order count and total price value
- Average customer rating and rating count
- City with the highest total price value
- Top food categories by total price value
- Top categories by rating
- Restaurants with the highest price totals
- Restaurants with the lowest average ratings
- Highest- and lowest-priced dishes
- Monthly sales/value trend
- Sales/value distribution by location
These summaries can help identify differences in food pricing,
restaurant performance, customer ratings and geographic patterns.

How to Use
1. Download or clone this repository.
2. Open the Excel workbook in Microsoft Excel.
3. Go to the Swiggy Data worksheet to explore the source records.
4. Review the pivot table worksheet for summary analysis.
5. Open the Dashboard worksheet to view the dashboard included in the
   workbook.
Project Purpose
This project demonstrates how spreadsheet-based analysis can turn a
large restaurant dataset into structured summaries that support business
understanding and data-driven observations.
